Readiness Copilot panel

Keep the map and brief visible while the Lee County agent answers questions in a persistent, follow-up-ready conversation surface.

Context

The previous blocking modal hid the command center, flattened Markdown into plain text, and offered no conversational continuity. The deployed map also lacked its JavaScript API key.

Alternatives

2 · Side panel · RecommendedPersistent conversation, minimize/close, Markdown, follow-ups, and per-answer Maps links.

Use the non-blocking side panel. Queries reuse /api/copilot/chat; Markdown renders headings, lists, emphasis, code, and links; Google Maps grounding links remain available per answer.
