Lee County · Florida · Equity audit

Who does the evacuation priority score reach?

The agent is finding real evacuation barriers, but its highest-priority tier is demographically different from the rest of Lee County. That is an audit signal to investigate—not proof of intent, and not a reason to delete race from the review.

Prepared 2026-10-20 · Recommendation only · No production changes made

Priority geography

Tract 208.01 / North Fort Myers is the highest-scoring tract (0.9545). It has 401 households without a vehicle, 98.5% mobile homes in the project data, and State B status because both nearby shelter accessibility fields are unrecorded. External ACS context places its median household income at $36,031 and poverty at 23.1%.

Other gap tracts in the top tier include Tract 501.04 (State D), Iona Tracts 19.16 and 19.23 (State D), Punta Rassa Tract 19.15 (State D), and Suncoast Estates Tract 203.01 (State B; 38.7% no internet in the project data).

Recommendation

  1. Keep the current physical-need score as the primary ranking.
  2. Add a parallel coverage/access-gap queue for poverty, language isolation, no internet, and no vehicle barriers.
  3. Require a pre-publication coverage check against county baselines and investigate large disparities.
  4. Test alternative weights and rank stability; add direct structural variables such as language access and transit reachability if gaps persist.
  5. Verify named State B shelters building-by-building before closing the gap; stage transportation for State D.
  6. Re-run this audit after every refresh with the data vintage, denominator, missingness, and weights recorded.

Limits

Race and ethnicity were not model inputs. ACS tract estimates have uncertainty; tract labels are not official neighborhood boundaries; the project view contains 221 populated tracts while Lee County has 223 total tracts, including two unpopulated. This memo recommends review and testing, not an automatic model change.
