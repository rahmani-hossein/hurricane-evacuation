State and county choice

Florida → Miami-Dade County

Florida is the strongest exercise state: the right hazard, the worst accessibility-recording gap in the comparison, and the second-most medical-needs shelters. Miami-Dade gives the demo enough scale for a transit and apartment-building story: about 2.7M residents, roughly 90,752 no-vehicle households, 138 registered shelters, and 130 shelters with accessibility unrecorded.

Scope: use one county for the demo, but keep the same action graph extensible to the other Florida counties.

Data verdict

Ready for exploration

BigQuery MCP can query the five tables now. The source extracts have valid coordinates and stable tract/facility identifiers.

Not ready as the agent contract

332 shelters have no usage, 2,318 have generator status unrecorded, 73 normalized duplicate groups exist, 46 tracts lack a hazard match, and Florida’s lack-of-transport field is entirely null.

Use raw → staging → operational marts

Normalize addresses and ZIPs, preserve tri-state fields, create reviewable shelter identity groups, add GEOGRAPHY points and spatial bridges, then expose narrow marts such as county_risk, tract_priority, shelter_readiness, medical_escalations, and peer_tasks.

Batch + runtime: batch-validate all shelters nightly or before the brief. Use Maps grounding only for the selected candidate shelters and refresh evidence deliberately before publishing.

Three modes, one action graph

1. Getting people out

Rank high-pressure tracts, match candidate shelters, estimate routes, and propose pickup corridors.

2. Shelter readiness

Gate destinations on EVAC/POST usage, surge exposure, recorded fields, and live Maps verification.

3. Medical escalation

Identify where medical evacuation capacity is unavailable or unverified. Recommend generators, transfer agreements, or health-department escalation.

Fallbacks

Every action has a backup captain, alternate destination, phone-tree path, and explicit “no response” state.

County risk model

Rank need relative to usable capacity, not raw population or shelter count:

30% vulnerable need + 25% destination gap + 20% hazard exposure + 15% medical dependency + 10% transport friction.

Keep a separate data-confidence score. A high-risk, low-confidence county becomes a verification priority—not a falsely precise ranking.

Neighbor Lift network

A safe, creative add-on for apartment buildings:

  1. Use public data to identify a tract/building cluster, never a named person.
  2. Residents voluntarily opt into a check-in pod for needs such as ride, mobility assistance, power backup, pet, or language support.
  3. Assign two-person buddy tasks with a backup and deadlines.
  4. Resolve each check-in as confirmed, needs county help, no response, or declined.
  5. Escalate failed tasks to county partners or a phone tree.
Guardrail: keep the demo synthetic at building level. Do not infer individual medical status or expose household-level data.

Build these tools

Core agent tools

  • rank_priority_tracts — explainable pressure score.
  • find_shelter_options — spatial candidate matching.
  • build_readiness_brief — evidence to action queue.
  • audit_claims — recorded, derived, Maps, unknown.

One add-on only

  • Florida shelter-demand plan for demand-side capacity.
  • Transit GTFS for scheduled reachability.
  • NOAA/NHC surge layers for scenario storytelling.
  • State care-facility licensing data to close the medical gap.

Frontend direction

  • Left: chat thread with action prompts.
  • Center: living map that updates with the conversation.
  • Right: Readiness Brief cards: Who, Where, What we know, Next action.
  • Bottom: evidence rail separating BigQuery, calculations, Google Maps, and unknowns.
  • Signature interaction: clicking a tract updates the chat context, map, shelter cards, and action queue together.
Trust is the differentiator. Show “unrecorded” in amber. Never turn a blank accessibility field into “no.”

Resident / peer mobile
