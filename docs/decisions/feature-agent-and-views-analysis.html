Migration decision

Adopt the agent logic and move its data products into gold. Do not only change the dataset string: the existing gold layer is Miami-Dade-specific. Create county-parameterized gold products for tract risk, shelter readiness, shelter options, access state, equity audit, and power dependence, then preserve the agent’s tool contracts and uncertainty semantics.

Recommended path

  1. Keep the State A/B/C/D, equity, medical-power, and Maps workflows.
  2. Promote the five Lee views into a stable county-scoped gold layer with snapshot and provenance fields.
  3. Remove Lee County hardcoding from prompts and SQL; validate county_fips as a tool parameter.
  4. Use Maps Grounding for named-facility verification and routing, not as a substitute for operational shelter records.
  5. For the hackathon, use Lee County if speed matters—the branch already passes live tests. Use Miami-Dade only if preserving the existing dataset/frontend scope is more important.
