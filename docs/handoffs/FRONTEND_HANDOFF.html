Connect the coordinator UI to one live agent and one gold contract.

The canonical demo is Lee County, Florida. The frontend should make the agent feel like a decision partner: a map selects the operational context, gold views explain the risk, and conversation turns that context into a defensible next action.

Read evacuation_readiness_gold; do not recreate raw-table joins in the UI.

Demo rule

Selected tract, access state, confidence, and caveats stay visible while the user chats.

Return a stable envelope with county, county_fips, snapshot_at, and rows. The map uses geo_id, lat, lon, stranded_score; shelter cards use shelter_name, address, distance, capacity, accessibility records, readiness confidence, and data quality.

Outreach discovery

Wire a prompt such as “Find trusted outreach partners for the top five Lee County tracts with State D access.” The agent first reads the curated lee_outreach_organizations gold table, then uses Google Search grounding to discover and verify nearby organizations.

Lead contract: label results curated_seed or search_discovered; show evidence URLs, verification time, and confidence. A lead is not proof of activation, staffing, willingness to deploy, shelter status, or medical capability. The agent can draft an outreach brief, but the UI must not send messages automatically.
