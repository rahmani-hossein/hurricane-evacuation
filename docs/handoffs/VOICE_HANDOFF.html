A voice layer that keeps the agent authoritative.

The browser streams audio to the API; Gemini Live handles natural conversation; operational questions route to the deployed ADK Agent Engine and its gold-backed tools.

TransportWebSocket at /api/voice
InputMono PCM, 16 kHz
OutputNative PCM audio plus transcript

Event contract

start → session_started; audio → user_transcript → audio; tool_started → tool_completed; agent_transcript → agent_turn_complete; error → text-chat fallback

Trust boundary

One source of truth: the gateway delegates operational questions to Agent Engine resource 5276937832231862272. The browser never receives credentials and never executes SQL or outreach actions.

Design decision

Push-to-talk first. It is easier to use during noisy operations, makes turn boundaries explicit, and leaves room for hands-free barge-in after field testing. Offline mode exposes cached instructions only and never invents a live answer.
