Agent contract for Hurricane Readiness

Core rule: query gold first; preserve “unrecorded” as uncertainty; use Maps for selected place identity and routes; never infer individual risk or shelter availability from proxy data.

Gold tables

shelter_readiness_snapshot

Source shelter rows with EVAC/POST semantics, tri-state evidence fields, capacities, duplicate groups, readiness score/confidence, and verification status.

tract_shelter_options

Populated tract to EVAC/BOTH shelter candidates within 50 straight-line miles. Distance is not drive time.

county_risk_snapshot

Statewide prioritization metrics and county score. Explain the score with underlying counts and timestamp.

miami_dade_tract_mobility_proxy

Miami-Dade-only proxy combining no-vehicle rate, mobility limitation, and no-internet rate. It is not CDC PLACES LACKTRPT.

miami_dade_tract_shelter_options

Miami-Dade tract/shelter options enriched with mobility proxy fields.

miami_dade_county_risk_snapshot

One-row county summary with average/max mobility proxy and caveat.

Agent language contract

  • Say “listed capacity,” not confirmed capacity.
  • Say “straight-line distance,” not travel time.
  • Say “mobility proxy,” not reliable transportation.
  • Say “accessibility unrecorded,” not inaccessible.
  • Say “needs current verification,” not open.
  • Never identify a person as vulnerable from tract aggregates.
